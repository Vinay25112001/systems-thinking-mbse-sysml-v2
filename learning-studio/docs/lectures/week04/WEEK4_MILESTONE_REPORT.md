Tool (`#/week/4/lab/tool`): imports `week3-model-inputs` v1 with Week 3's own importer (refuses Week 1, Week 2 and Week 4
files, AeroLink, and records without requirements or capabilities), seeds one viewpoint per required kind, and builds the
viewpoints, mission and first-level functions, functions, logical, physical and external elements, the allocation table,
decisions, information items and AI cards; exports `week4-model-inputs` v1 JSON and a Markdown record; imports a
teammate's export. Hard gates (real defects only), each tested both ways in `record.test.ts` and in the DOM
(`Week4LabTool.test.tsx`, 5 tests). After review M2 every gate is justified by a sentence of the lecture (table in
`WEEK4_REVIEW_DISPOSITIONS.md`), and word minimums sit at the shortest valid entry:
- viewpoint: kind; purpose ≥ 3 words; stakeholders and a concern (one word or a CON-ID); any NEED/CAP/REQ it names exists
  (none named is an advisory); conventions stated;
- function: name not an element's name; an input and an output; an existing capability; an existing scenario or a planning
  reason; a first-level function; allocated requirements exist. A one-word name, a thing-like name and no requirement are
  advisories only (lesson of the Week 2 review M1: a valid entry is never rejected for its form);
- allocation: existing logical and physical elements; the physical one reached by the logical one; a criterion and a
  sentence. Every system requirement must be allocated to a counted function or a physical element (part-level);
- decision: question ≥ 3 words; ≥ 3 alternatives; the chosen one listed (case and final punctuation ignored); rationale
  ≥ 5 words; an existing NEED/REQ/R/CAP/TPM;
- information: name and content; data and information, not the same text; producer and consumer each a physical element,
  external element or AI card; decision ≥ 2 words; an existing FN/REQ/DEC reference. No route, an AI producer (oversight
  reminder), same element (judged at an AI's host) and personal content without a sensitivity are advisories;
- AI card: host, supported function, existing input items, outputs, oversight, failure mode.
The four consistency checks are computed and shown. The fixture is the Riverside Food Bank Network continuing its Week 3
record; it passes every check.
