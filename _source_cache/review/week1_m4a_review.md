# Independent review: Week 1 reconstruction, Milestone 4 part A

Reviewer: independent agent (read-only, adversarial). Date 2026-10-21.
Scope: the uncommitted M4A tree (Week 1 five-stage navigation, the Learn textbook reader, the IF-1 boundary explorer, the homepage and Week 1 Overview, the unified student chrome, the extended leak check). Builder report: `learning-studio/docs/week1/M4A_REPORT.md`. Week 6, `server/**`, `src/project/**` and `// --- auth ---` blocks are excluded.

## Verdict: REVISE

The engineering is solid. The reader grid matches the spec to the pixel, the chrome is consistent, the redirects work, the student build passes, the regression probes show no change to other weeks, axe finds no violations, and every citation I spot-checked (25 of 25) is supported on the cited page. Two problems block sign-off. First, the A25 faculty decision on "objectives" is applied only to titles and the rail, so the student-visible text still says "goal(s)" in about a dozen places. Second, the Overview's time table uses a different, unflagged workload model: it counts optional practice and leaves out 1.0 h of required work. There is also a cluster of student-visible slide pointers, stale "Session N / lesson / below" cross-references and an internal rubric code. The student-text leak scan cannot see these, because it reads only the chapter body.
