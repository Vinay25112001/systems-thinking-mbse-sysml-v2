`src/project/adapters/week1.ts`. Current labels are in `src/workbench/week1/TeamView.tsx`. Gates are in `team.ts` and `needQuality.ts`.

## Summary of fields lacking a sourced definition

Domain; problem statement; mission; goals/objectives; enterprise suitability ("why"); external "kind" (system vs actor); direction; relationship
types (all seven); interest; assumptions; unknowns; AI usage statement (policy). Of these, problem statement, mission and goals have a
nearby source (R10 pp.543–544, BMA outputs) but no definition; the rest are course conventions and must be labelled as such in the guidance
(§5: never invent a source).

Fields whose guidance can be assembled **entirely from existing text**: lead roles, decision rules, norms, prefixes, enterprise name, SoI, PRT,
external system name, crosses, stakeholder name, role, stage, side, approving authority, concern, influence, reason, all ten need fields.
