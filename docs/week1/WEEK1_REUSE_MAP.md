# Week 1 reuse map

Prepared 2026-10-21 for milestones M0/M1 of the Week 1 reconstruction (directive
`docs/directives/2026-10-21_MASTER_IMPLEMENTATION_DIRECTIVE_WEEK1.md`, §4, §5, §9, §18). This is a document, not a change: no source file was
edited. Paths are relative to `learning-studio/` unless stated otherwise. Line numbers come from the **working tree on 2026-10-21**, which
has uncommitted changes (`src/workbench/week1/team.ts` imports the untracked `src/workbench/emptyAnswer.ts`; audit LB-5). Re-check the
line numbers before you rely on them.

## 0. Verdict legend and target structure

| Verdict | Meaning |
|---|---|
| **KEEP AS IS** | Reused unchanged. Only its call site or route moves |
| **ADAPT** | Reused with stated changes: re-sequencing, relabelling, new metadata, a new render |
| **REPLACE** | A new implementation takes over the role. The old source can be removed only after the replacement is tested, and teaching text is never deleted (§5) |
| **RETIRE-FROM-STUDENT-NAV** | Stays in the source and in the faculty build. No student route, link or bundle reaches it |

Target student structure (§8, §9): **Homepage → Week 1: Overview → Learn → Guided Practice → My Project / Lab → Review & Submit**.
Faculty-only: lecture slides and faculty notes, the handout, `.pptx` export, answer keys and exam banks.
